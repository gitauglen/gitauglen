# Glen Gitau

Financial data engineer building capital markets infrastructure 
for East Africa.

I work at the intersection of finance and technology — 
automating the extraction, structuring, and visualization of 
financial data across Kenya's banking sector and government 
securities markets.

---

## What I Build

**Financial Data Pipelines**
Extraction engines for Kenyan bank quarterly filings — 
pulling NPL metrics, capital ratios, and income statement data 
from PDFs using Python, OCR, and LLM-based structuring into 
PostgreSQL.

**Capital Markets Visualizations**
Daily data products for The Kenyan Wall Street — CBK T-bill 
auction cards, Kenya government securities yield curves, and 
global rates transmission charts built with Chart.js and Python.

**Sector Research Infrastructure**
Multi-year financial ratio databases for Kenya's Tier-1 banks. 
Quarterly extraction engine (`bank_extraction_quarterly_v1.py`) 
with structured JSON outputs and Google Sheets mirroring.

**Web & API Infrastructure**
Partner content APIs on Next.js + Cloudflare Workers, CMS 
integrations via Directus, and production deployments on GCP 
and Cloudflare Pages.
